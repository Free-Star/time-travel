# 时空相册开发计划

## 最高优先级约束

媒体文件绝对只读。程序不修改媒体内容或元数据，不移动、不重命名、不删除文件。所有派生数据均存放在相册之外。

`viewTools` 是开发工作区，媒体扫描器必须明确排除该目录。

## 阶段

1. ✅ 项目骨架、只读访问层与写入拦截。
2. ✅ SQLite 数据模型、媒体扫描和增量索引。
3. ✅ 缩略图、视频封面和缓存队列。
4. ✅ 虚拟化时间线与媒体查看器。
5. GPS、地图聚合和时间地图联动。
6. 事件划分、搜索及数据库覆盖式修正。
7. 性能、容错、打包和媒体不变性验收。

每个阶段必须通过构建、单元测试和相应验收后才进入下一阶段。
